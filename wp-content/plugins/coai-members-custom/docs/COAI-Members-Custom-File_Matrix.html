C) Immediate “attention flags” (not fixes, just flags)

  • Legacy / Duplicate admin-portal.php and admin-members.php overlap in member directory functionality. Expect permission logic + filters to differ.
  • Risk Area admin-members.php contains a “fallback” coai_staff_can() definition. That can drift from /includes/helpers/staff-permissions.php and create inconsistent access rules.
  • Risk Area Authentication + role mapping spans MU plugins (coai-auth-bridge.php) and staff gating spans plugin helpers (coai_staff_can) — this is correct architecturally, but it means “identity” can be interpreted differently in different places if not kept consistent.
